# 日文單字提醒（PWA）

純網頁版的日文單字提醒 App。可選 N5~N1 難度，設定提醒間隔後，會定時跳出通知教你一個日文單字（漢字/假名 + 中文翻譯）；也可以直接在 App 裡手動抽卡背單字。

## 檔案說明

- `index.html` / `styles.css` / `app.js` — 主畫面與邏輯
- `words.js` — 單字資料庫（依 N5~N1 分類），格式：`{ k: 漢字, r: 讀音, m: 中文意思 }`，要加單字直接照格式加進對應等級的陣列即可
- `word-picker.js` — 「抽籤袋」演算法：同一組難度的單字會先全部隨機出過一輪才會重複
- `sw.js` — Service Worker，負責離線快取 + 背景通知（periodic background sync）
- `idb.js` — 給網頁與 Service Worker 共用的 IndexedDB 存取小工具
- `manifest.webmanifest` + `icons/` — PWA 安裝設定與圖示

## 在手機上安裝、測試

因為瀏覽器規定「通知」與「Service Worker」只能在 **HTTPS** 或 `localhost` 底下運作，要在手機上實際測試，必須先把這個資料夾放到一個有 HTTPS 的地方。最簡單、不用寫任何後端的兩個選項：

### 方法一：GitHub Pages（免費、穩定，推薦長期使用）
1. 在 GitHub 建一個新 repo，把 `JapaneseWordReminder` 資料夾內容 push 上去
2. Repo 設定 → Pages → 選擇 branch（例如 `main`）與根目錄，儲存
3. 幾分鐘後會拿到一個 `https://你的帳號.github.io/repo名稱/` 網址

### 方法二：surge.sh（不用註冊帳號，一行指令，適合快速測試）
```bash
npm install -g surge
cd JapaneseWordReminder
surge
```
指令跑完會直接給你一個 `https://xxxx.surge.sh` 網址。

### 安裝到手機主畫面
用手機瀏覽器（Android 用 Chrome、iPhone 用 Safari）打開上面拿到的網址：
- **Android (Chrome)**：選單 →「加入主畫面」/「安裝應用程式」
- **iPhone (Safari)**：分享鍵 →「加入主畫面」（iOS 需 16.4 以上才支援網頁通知）

加到主畫面後，用那個圖示打開才算是「已安裝的 PWA」，通知與背景喚醒效果最好。

## 使用方式

1. 打開 App，勾選想學的難度（可複選 N5~N1）
2. 選提醒間隔（15 分鐘 ~ 4 小時，或自訂分鐘數）
3. 按「啟用通知提醒」，允許瀏覽器的通知權限
4. 想馬上看效果可按「立即測試一則通知」
5. 也可以直接用下方「隨手抽一個單字」卡片手動背單字，不會發通知

## 背景通知的技術限制（誠實說明）

這是純前端網頁 App，**沒有伺服器主動推播**，所以無法像原生 App 一樣保證「手機關機/App 被滑掉後還能精準定時跳通知」。實際行為：

- **App 開著（含背景分頁）**：會用計時器準時跳通知
- **App 被切到背景一段時間後又打開**：只要已經超過設定間隔，一打開就會立刻補跳一則，不會漏字
- **Android Chrome 且已安裝到主畫面**：會嘗試註冊 Periodic Background Sync，讓瀏覽器在背景也能定時喚醒觸發通知；但實際間隔由 Chrome 依你的使用頻率決定（通常間隔會被拉長到數小時以上），不保證跟你設定的分鐘數一致
- **iOS Safari**：只有加到主畫面且 iOS 16.4+ 才支援通知，背景喚醒的支援更有限

如果之後想要「App 完全關閉、手機鎖屏時仍然精準定時跳通知」，唯一可靠的做法是加上一個小型後端伺服器，用排程（cron）搭配 Web Push 主動推播給所有訂閱的手機——這是目前架構之外的下一步，需要的話可以再擴充。

## 擴充單字庫

打開 `words.js`，找到對應等級（`N5`/`N4`/`N3`/`N2`/`N1`），依照既有格式增加物件即可，不需要改任何其他程式碼：

```js
{ k: "漢字", r: "かな", m: "中文意思" }
```
